# RZXXY AI Marketing Assistant

An AI-powered marketing assistant designed to help with marketing research, content creation, copywriting, email marketing, advertising, and sales strategy.

## Features

- AI-powered marketing assistance
- Gemini AI provider integration
- Marketing knowledge base
- Content and copywriting support
- Email marketing guidance
- Facebook Ads knowledge
- Lead magnet and sales letter resources
- Category-based AI responses
- Interactive command-line interface
- Automated tests
